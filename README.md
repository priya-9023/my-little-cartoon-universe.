# My Little Cartoon Universe 🌈

A personal beginner-friendly cartoon creativity studio with a virtual trinket shelf, original character creator, three-panel comic maker, drawing pad, and Animation Academy with lesson progress and a mini animation player.

## Use
Open `index.html` in a browser. On GitHub Pages, publish from the `main` branch and the `/ (root)` folder under **Settings → Pages**.

## Save your projects
Website code lives in GitHub. Trinkets, characters and saved comics currently live in your browser's local storage and **do not automatically sync between devices**. Use **Download my backup** in Animation Academy, then import that JSON on another device. Drawings need to be exported separately as PNG.

## Sharing
The comic maker can export an image for you to post manually on a social network. There is no public story feed or user-account system yet. A community platform will need authentication, a database, media hosting and moderation.

## Rights
Existing cartoon titles are fan references; do not upload or publish other creators' protected images or characters in stories unless you have permission or another legal basis.
